# Delivery playbook

Before declaring completion, re-run the full checks after any final simplification, then map every acceptance criterion to evidence and classify it **Verified / Partially verified / Untested**. Confirm the completion standard in SKILL.md is met; if it is not, report the project as incomplete. Report: delivered scope, important decisions, files changed, checks actually run, whether the independent review was real, the security status (final security review run or "not required: reason"; methods used: static inspection / automated scanning / penetration testing, the last "not performed" unless authorized; open findings by severity; accepted High findings listed as open residual risk, never as fixed; never "secure"), unresolved defects/risks, unverified areas, required user actions, and any follow-up milestone. Never imply deployment or external publication occurred unless confirmed.
