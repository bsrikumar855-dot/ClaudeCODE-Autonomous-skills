# Delivery playbook

Before declaring completion, re-run the full checks after any final simplification, then map every acceptance criterion to evidence and classify it **Verified / Partially verified / Untested**. Confirm the completion standard in SKILL.md is met; if it is not, report the project as incomplete. Report: delivered scope, important decisions, files changed, checks actually run, whether the independent review was real, unresolved defects/risks, unverified areas, required user actions, and any follow-up milestone. Never imply deployment or external publication occurred unless confirmed.
