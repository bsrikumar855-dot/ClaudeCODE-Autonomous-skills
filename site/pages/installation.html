Install the AUTO-BUILDER Claude Code skill

Requires Claude Code and Git. The installer only copies files: it never edits your settings, permissions, hooks or CLAUDE.md.

Jump to: Linux / macOS / WSL · Windows · Manual · Verify · Update · Hooks · Uninstall

Linux, macOS, WSL and Git Bash

git clone {{GH}}.git
cd ClaudeCODE-Autonomous-skills

./install.sh --personal                 # all your projects (~/.claude)
./install.sh --project /path/to/repo    # one project (<repo>/.claude)
./install.sh --project --dry-run        # preview, writes nothing

Windows (PowerShell)

git clone {{GH}}.git
cd ClaudeCODE-Autonomous-skills

.\install.ps1 -Personal
.\install.ps1 -Project -Path C:\path\to\repo
.\install.ps1 -Project -DryRun
install.ps1 has not been executed by the author yet (no PowerShell was available during development). It mirrors the tested shell installer; please report any problem as an issue. If scripts are blocked: powershell -ExecutionPolicy Bypass -File .\install.ps1 -Personal.

Manual install

Copy .claude/skills/auto-builder/ and .claude/agents/*.md from the repository into ~/.claude/ (personal) or your project's .claude/ directory. Opening Claude Code inside the cloned repository also works without installing.

Verify the installation

  1. Confirm SKILL.md exists at .claude/skills/auto-builder/SKILL.md (project) or ~/.claude/skills/auto-builder/SKILL.md (personal), and nine files exist in the matching agents/ folder.
  2. Start a new Claude Code session and type /auto-builder; it should appear as a command.

Installer output labels each file INSTALL, UPDATE, PRESERVE (yours differs and was kept), CONFLICT (a symlink or directory is in the way) or STALE (left over from an older version).

Update

git pull
./install.sh --personal --update     # replaces differing package files, keeps .bak backups

Enable the optional hooks

Hooks are off by default. The JSON to add to .claude/settings.json, and their limits, are in the README. They require jq.

Uninstall

Delete the auto-builder folder under skills/ and the nine agent files (product-manager.md, researcher.md, architect.md, frontend-engineer.md, backend-engineer.md, ai-engineer.md, qa-engineer.md, security-engineer.md, critical-reviewer.md) from agents/. Check first that none are your own files of the same name.
