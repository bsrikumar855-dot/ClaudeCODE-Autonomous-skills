What is AUTO-BUILDER?

It is a reusable Claude Code skill plus Claude Code subagents that encode an AI software development workflow: discover the real problem, define testable requirements, design the architecture, plan small tasks, implement, verify, review and deliver. It targets one common failure of autonomous coding agents: jumping straight to code and declaring success after a single green build.

Goal in, plan first

Describe an outcome in plain language. The lead agent inspects your repository, writes requirements and a task list with acceptance criteria before editing code.

Specialist subagents

Nine roles from product manager to security engineer, each with a least-privilege tool list. Reviewers, QA and security have no edit tools.

Verified, not trusted

Work proceeds in milestones that each pass a verification gate. Checks must actually run, a separate reviewer inspects important milestones, and the report labels each criterion Verified, Partially verified or Untested.

Autonomy with checkpoints

Routine decisions are made for you. It asks before deploys, spending, destructive data operations, secrets, pushing, or changes of product direction.
